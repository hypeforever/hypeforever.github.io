Hello everyone : )

Recently I've noticed some bugs in our site and every member should be aware of them. Keep in mind that while me, Moonlighter (creator of hypeforever) will try and help you guys with all the issues I can solve, our site is hosted under webs.com (which I do not own) and therefore I can't do anything to fix problems related to the engine this host uses.

We seem to be having problems with the messaging system. Some messages do not reach their recipient (nor via DM nor via profile comment), specially when they contain links. And there is no warning to that, sometimes you'll see your message sent\posted on the user's profile and then it will delete itself. I'll leave some tips and workarounds regarding this problem:

1 - Do not send links via message \ profile comment.

It may disappear or never reach the user.

2 - Befriend anyone that you wanna send a personal message

It also seems that, altough the option is avaliable, you can't send personal messages (or direct messages) to users that you are not friends with.

3 - If it's an important message, check with the person if the message was received.

Following these steps, we can workaround this problem that I believe to be temporary.

~Moonlighter
