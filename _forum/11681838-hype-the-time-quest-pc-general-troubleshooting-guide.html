Hello Everyone!
I decided to create this to further aid people who are having troubles with HTTQ.

I can't install the game/ The install software doesn't run correctly/freezes

PROBLEM: It is not possible to use the installer that comes with the Hype CD in newer Windows versions.

SOLUTION 1: Install the folders in a older OS (or a Virtual Machine) then copy the folders

"C:\Windows\Ubisoft" and C:\Ubisoft\Hype The Time Quest"

To your computer, to the same locations (C:\Windows & C:\Ubisoft)

SOLUTION 2: Download those folders from our Downloads section.

I could install the game on a newer OS, but the game doesn't work properly (it has bugs), the loading bar does not finish loading and I get an error message, etc

PROBLEM: The game was not installed properly, even if the installer seems to be working normally.

SOLUTION : Same as above.

My game opens, but there are black artifacts all over the screen.

PROBLEM: The Direct X Executable is not compatible with newer versions of Windows

SOLUTION: Download nGlide and play using "MAIDFX_BLEU.EXE".

My game opens, but I can't save.

PROBLEM: Something to do with the game being unable\unauthorized to create folders and files

SOLUTION 1: Go to the executable's proprierties tab, change it to Windows 2000, check the "Run as Admin" box

SOLUTION 2 : IF #1 doesn't work, download savegame folders from Hype Forever and install them. Save your own games over the downloaded files.

My game starts, but it's all black.

PROBLEM: Either the first video or a general video glitch. Two possible solutions

SOLUTION 1: Go to C:\Windows\Ubisoft\ubi.ini , locate [Hype - The Time Quest] and change the line PlayVideo = 1 to Playvideo = 0

SOLUTION 2: Apply the official patch to your game

EXTRA: Go to the executable's proprierties tab, change it to Windows 2000, check the "Run as Admin" box.

OBS: Since it's not possible to determine exactly why your screen is all black, you may have to play around with 1, 2 and EXTRA to get results.

My game doesn't start.

PROBLEM: General Newer OS Incompatibility issues.

SOLUTION 1: Go to the executable's proprierties tab, change it to Windows 2000*, check the "Run as Admin" box.

*If it doesn't work, try the older and then the newer Operational Systems listed.

SOLUTION 2: Apply the official patch to your game.
