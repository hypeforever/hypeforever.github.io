I have the solution for your problem. When you start the game, and you're in the menu, alt-tab and go to your Hype installation folder. Inside the folder Gamedata, create a folder called SaveGame and inside that folder create another one called HYPE. This doesn't work if you already have this folders before you start the game. It's the only way I could fix my portuguese version to have working save games.
