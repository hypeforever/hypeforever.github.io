Ok so we are at the point where we must discuss which engine to use. Although I do think Hype Team should discuss this via Skype , I'll post this here so that people that aren't in the team can also opine.

As of now, I see two arguments making their points.

The first one is "Start from the scratch (or select an engine like OGRE) and create Hype The Time Quest 2 there.


Positive points:

-Easier to get started, since it's a clean white board where we can write anything we want on.

-The usual glitches found in Hype - The Time Quest (3DFX Emulated Version) will be gone

-It will become much easier to run the game in newer systems, and more people will be able to play it

-The graphics, models and characters can all be improved

-The project will be more organised and easier to control, since it will be all content we created ourselves.

Negative points

-We'd have to start almost from the scratch - custom models, music, story, scenarios, etc

The second one is to reverse-engineer the current Hype - The Time Quest engine, and create a new game from it.

Positive aspects:
-The events, character base and everything is partially done, so we'd only have to change it, like a mod


-We keep the feeling and atmosphere present in the original game


-We'd get the game done faster


Negative Aspects:

-The bugs, glitches and all other problems will still be present, and reserach on how to fix those would be necessary, so that everyone could play without having to add or modify files by themselves etc


-As of now, we don't know about the current engine's capabilities. Because of that, it's unknown how much more it can be expanded, how many levels it supports, how much improvment can be done, etc. That may be a limiter.


-All the things that have to be deleted and replaced can take a long time, or make the project messy.


-Because we probably need to design editors for game content, it can delay the whole process.

I just wanted to expose these here. I wanna hear everyone's opinions on this,so that we choose the best option for all.

Hey guys, I've got a quick question - as this is such a massive project I was thinking whether it would be a good idea to reverse engeneer the original game or use a (graphics-only) engine like OGRE.

If we use an engine with support for sounds/networking/etc. and perhaps even with a GUI/Editor to work with, we would save a big amount of time we could use for better story/game assets/quests etc.

An engine like Unity, CryEngine, or the UDK might come in handy as the core basics of the engine (like rendering assets, lighting, sounds, cut scenes, ...) are already written. With most of the engines, we would only have to write the behavior of the objects/persons/assets and not the fundamentals, which will really take the pressure of the programmer(s).

So far from my point of view.

Btw, for those who don't know me yet, I'm a 17-year-old German Hype The Time Quest lover and want to work with you on this game/sequel/remake/...

It's cool to see there are other people out there loving the love behind the game as much as I do.
