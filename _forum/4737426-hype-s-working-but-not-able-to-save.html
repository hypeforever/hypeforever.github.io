Solution of problem with savegame (folders "Hype", "Savegame0", "Savegame1" etc.) hadn't helped me on both polish and english versions (at least on my PC). Another solution which I found is to start new adventure, and just after a movie to create in ...\Hype - The Time Quest\Gamedata\Savegame one folder "HYPE". It's needed to use WIN key to get to desktop, therefore the game often crashes (fortunately not everytime). Then I was able to save my first game without problem (as I remember well, it worked on every language version of game). I needn't have to create "Savegame0" etc. folders myself.

The easiest solution is however to put a "starter" savegame, and to skip tutorial.

What's more, if the "HYPE" folder is not created, and the game isn't saved anytime, application doesn't remember some important settings of game. For example if you destroy all the beehives in Forest and go to another location, you will see the same beehives untouched when you return there. This is secret of my photo: https://hypeforever.github.io/photos/, where I can destroy every beehive as many times, as I want (it's possible to reach even 100/10 if sb wants :D).
