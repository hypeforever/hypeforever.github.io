Here I will explain how to get a Xbox Controller to work on Hype the Time Quest Step by Step. Other contollers should also work, but I have not tested.

I haven't found anyone on the internet explaining how to get a controller to work on Hype the Time Quest, so I decided to do it now since I have time. Some info first:

  • JoyToKey enables PC game controllers to emulate a mouse and the keyboard input.
  • To get JoyToKey to work on Hype the Time Quest you have to run the game on Windows Vista, 7 or 8 compatibility mode.
  • JoyToKey didn't work on Windows 95,98 and XP compatibility mode for me.
  • I don't remember if JoyToKey works without compatibility mode, I think it deosn't on Windows 8.1. I have upgraded to Windows 10, so I'm unable to test that now, and I'm unable to get Hype the Time Quest to work on WIndows 10.

Step 1:

Download "JoyToKey", or any other program that enables PC game controllers to emulate a mouse and the keyboard input. "Xpadder" could also work, but I have not tested that program because the program didn't work for me on Windows 8.1.

JoyToKey link: https://joytokey.net/en/download

Step 2:

Open the program and assign what keyboard key you want on each button. To assign a key to each Trigger-button you have to go to "Options<Show/Hide buttons<Stick/POV" and choose "show all axes (8 way + POV x 2)"

Left Trigger (LT) will show as "Axis 5 (>)"

Right Trigger (RT) will show as Axis 5 (<)"

Step 3:

Run Hype the Time Quest with Windows Vista, 7 or 8 compatibility mode.

That's it, your xbox controller should work now, it worked for me atleast when I was on Windows 8.1. I'm on Windows 10 now and unable to run Hype the Time Quest at all. If anyone have had problems running this game on Windows 10 and found out a fix, please tell me on this forum page: https://hypeforever.github.io/forum/topics/13225086-hype-on-windows-10/

Edit: After further testing, it apears that it's possble to make the controller work on Windows XP and lower compatibility mode. When you run the game on Windows XP and lower compatibility mode, the PC needs administator rights to run the game. If you want the controller to work, you need to run JoyToKey with administrator rights too.

Conclusion: If the game runs with administator rights, JoyToKey (or any other similar software) needs to run with administrator rights too to function in-game. That means the controller will be able work in-game no matter what compatibility mode you use, as long as JoyToKey is also running with administrator rights.
