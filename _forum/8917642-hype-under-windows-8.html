Recently, a member came up with a problem\bug I had never seen:

An "Out of Memory" message error issue while trying to run Hype under Windows 8. If you see this message, even when you have lots of memory (eg. 8 gb), you'll need to limit the memory so the game works correctly. I know it doesn't seem logical, but there is a reasonate explanation for this, that you can google and (try) to understand.

1.Open the "Start" menu

2.Type in "msconfig" and hit enter.

3.In the "boot" tab, choose "advanced options"
4. Check the "Maximum Memory" box and set it to 1024 or 2048

5.Reboot your pc.

6.The game should now work perfectly.

CAUTION! This method limits the amount of memory avaliable for usage and it affects ALL applications. If you run software or games that need more memory, you'll have to change this setting back and forth.
