You need some stuff in order to make it work on a windows 7 - 64 bit. You'll need to install the game in a older windows installment, then copy C:\Windows\Ubisoft and C:\Ubisoft\Hype - The Time Quest to your new pc, in the same places. Also, you can't play it without nGlide's patch, which will allow you to play the 3dfx version. There are very, very small bugs that won't interfere with gameplay.
