Hi everyone,

I recently re-installed Hype The Time Quest on my Laptop (Windows 7) using your uploaded installer (German Version) which finally allowed me to play the game again without having to switch back to an older PC - so first: Thanks for all the effort! ;)

Everything worked fine until about September 9th / 10th when a huge Windows Update was released which my laptop installed automatically. After that, the game wouldn't start anymore - kind of as you describe in the "bugs and problems" section, the screen didn't even go black.

When opening the Task Manager, I could see the game file "MaiDFXvr_bleu" did in fact open up for a couple of seconds, but then just seemed to close again by itself.

I "solved" the problem by taking the radical way - uninstalling all the updates from September 9th and 10th manually - and the game would work again as usual. For the time being, I've changed my system settings to ensure updates are only downloaded, but not installed automatically. In addition, I've set a "restoration point" (or whatever the English technical term for this may be :D ) to be able to reset the system to a previous state in case any unwanted updates should be installed without my knowledge.

However, there will probably be some needed Windows updates in the future, so refusing to update can't be a permanent solution.

Has anyone else tried to play Hype: The Time Quest since September 9th and experienced similar problems? Is there a way to identify which particular one of the myriad of updates that was installed that day is "guilty" of making the game crash?

Thanks in advance!
