Sorry for being slow to answer, but this is what helped me when I had the same problem:

Open your ubi.ini file, that is located in

C:\Windows\UbiSoft

Find the line below [Hype - The Time Quest] that reads

playvideo = 1

and change it to

playvideo = 0

then save and replace the existing file.

After that, make sure to run the game as an adminstrator. Hopefully this helps you guys too.
