I did as I described in this topic to be able to save the game on Windows 7 64 bit: http://hypeforever.webs.com/apps/forums/topics/show/4737426-hype-s-working-but-not-able-to-save-

But the game still didn't remember any changes in options. The solution is one of these two things (I did both at the same time and I'm too lazy to check which one fixed the problem):

1 - create a folder Options in /Gamedata

- copy Default.cfg from the same location on your Hype CD to the folder you just created

2. - right click your Hype - The Time Quest folder in Windows

- uncheck read only attribute box, click ok in the window that appears. If you check later the checkbox will still be filled, don't worry about that

- for that folder, go to Security, Advanced, Change permissions and give permission "Full control" to group "Everyone"

After I did both of those things, and changed some settings in the game, Current.cfg appeared in the Options folder and the game remembered settings normally.
