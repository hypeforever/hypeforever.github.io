## Save Game Files

![Hype in the forest]({{ "/assets/images/downloads/savegames.jpg" | relative_url }}){: width="354" height="287"}

Here are my save game files so you can download and play : )

- [Era of Taskan I.rar]({{ "/assets/downloads/savegames/era-of-taskan-1.rar" | relative_url }})
- [Era of Taskan II.rar]({{ "/assets/downloads/savegames/era-of-taskan-2.rar" | relative_url }})
- [Era of Taskan III.rar]({{ "/assets/downloads/savegames/era-of-taskan-3.rar" | relative_url }})
- [Era of Taskan IV.rar]({{ "/assets/downloads/savegames/era-of-taskan-4.rar" | relative_url }})
- [Search for the Flags and Barnak.rar]({{ "/assets/downloads/savegames/search-for-the-flags-and-barnak.rar" | relative_url }})
- [All Saves.rar]({{ "/assets/downloads/savegames/all-saves.rar" | relative_url }})

These contain folders named SaveGameX (X ranging from 0 to 9). Each folder
corresponds to one SaveGame slot on your SaveGame page.

Copy the folders to

```
C:\Ubisoft\Hype - The Time Quest\Gamedata\SaveGame
```

You can also change the number on the end of the folder's name if you want to
use another slot for the save.
